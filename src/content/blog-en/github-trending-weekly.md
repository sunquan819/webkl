## TOP 1: Cursor AI Code Editor (Weekly +5000 stars)

### Project Info

- GitHub: cursor-so/cursor
- Language: TypeScript
- Weekly star growth: 5000+ (fastest in history)
- Total stars: 50,000+

### Project Intro

Cursor is AI-based code editor, similar to VSCode but built-in AI assistant.

When coding, Cursor automatically:
- Completes code snippets
- Explains code logic
- Refactors code structure
- Finds errors and fixes

Like having senior programmer sitting beside you, helping anytime.

### Why Hot?

Cursor hot because:
- AI programming threshold lowered (ordinary people can code)
- Smooth editor experience (VSCode users seamless switch)
- Free use (basic features)
- Big companies all using (Google, Microsoft employees internally recommend)

### How To Use?

**Download Install:**
Visit cursor.so, download Mac/Windows/Linux version.

**Usage Experience:**
1. Open Cursor, import existing project
2. When coding, AI auto-complete (press Tab to accept)
3. Ask AI questions: press Cmd+K, input question (like "What's wrong with this code?")
4. Refactor code: select code, Cmd+K, input "Refactor this code"

**Who Suits?**
- Beginner programmers: AI helps you code
- Senior programmers: AI improves your efficiency
- Product managers: rapid prototype development
- Learners: AI explains code logic

## TOP 2: LocalGPT Local Run GPT (Weekly +3000 stars)

### Project Info

- GitHub: Private-AI-Project/Private-AI
- Language: Python
- Weekly star growth: 3000+
- Total stars: 25,000+

### Project Intro

LocalGPT lets you run GPT model on local computer, no API, no cloud, complete privacy.

Similar to ChatGPT, but:
- Data doesn't upload to cloud (privacy protection)
- No paid API (free use)
- Customizable model (personalized adjustment)

### Why Hot?

LocalGPT hot because:
- Enterprise privacy needs (data can't leak)
- Personal save money needs (API fees expensive)
- Developer debug needs (local test)
- AI democratization needs (everyone can use)

### How To Use?

**Install Steps:**
```
git clone https://github.com/Private-AI-Project/Private-AI
cd Private-AI
pip install -r requirements.txt
python run.py
```

**Requirements:**
8GB RAM, suggest 16GB. GPU optional, CPU can run too.

**Usage Experience:**
Browser open localhost:8080, use like ChatGPT conversation.

**Who Suits?**
- Enterprise users: process privacy data
- Developers: local test AI apps
- Personal users: free use GPT
- Researchers: AI model research
