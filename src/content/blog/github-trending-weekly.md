## TOP 1: Cursor AI代码编辑器（周增5000+star）

### 项目信息

- GitHub: cursor-so/cursor
- 语言: TypeScript
- 本周star增长: 5000+（历史最快）
- 总star: 50,000+

### 项目简介

Cursor是基于AI的代码编辑器，类似VSCode但内置AI助手。

写代码时，Cursor自动：
- 补全代码片段
- 解释代码逻辑
- 重构代码结构
- 查找错误和修复

就像有个资深程序员坐在旁边，随时帮你。

### 为什么火爆？

Cursor火爆因为：
- AI编程门槛降低（普通人也能写代码）
- 编辑器体验流畅（VSCode用户无缝切换）
- 免费使用（基础功能）
- 大公司都在用（Google、Microsoft员工内部推荐）

### 怎么使用？

**下载安装：**
访问cursor.so，下载Mac/Windows/Linux版本。

**使用体验：**
1. 打开Cursor，导入现有项目
2. 写代码时，AI自动补全（按Tab键接受）
3. 问AI问题：按Cmd+K，输入问题（如"这段代码有什么问题？")
4. 重构代码：选中代码，Cmd+K，输入"重构这段代码"

**适合谁？**
- 新手程序员：AI帮你写代码
- 资深程序员：AI帮你提高效率
- 产品经理：快速原型开发
- 学习者：AI解释代码逻辑

## TOP 2: LocalGPT本地运行GPT（周增3000+star）

### 项目信息

- GitHub: Private-AI-Project/Private-AI
- 语言: Python
- 本周star增长: 3000+
- 总star: 25,000+

### 项目简介

LocalGPT让你在本地电脑运行GPT模型，无需API、无需云端、完全隐私。

类似ChatGPT，但：
- 数据不上传云端（隐私保护）
- 不用付费API（免费使用）
- 可自定义模型（个性化调整）

### 为什么火爆？

LocalGPT火爆因为：
- 企业隐私需求（数据不能外泄）
- 个人省钱需求（API费用高昂）
- 开发者调试需求（本地测试）
- AI民主化需求（人人可用）

### 怎么使用？

**安装步骤：**
```
git clone https://github.com/Private-AI-Project/Private-AI
cd Private-AI
pip install -r requirements.txt
python run.py
```

**配置要求：**
8GB内存，建议16GB。显卡可选，CPU也能运行。

**使用体验：**
浏览器打开localhost:8080，像使用ChatGPT一样对话。

**适合谁？**
- 企业用户：处理隐私数据
- 开发者：本地测试AI应用
- 个人用户：免费使用GPT
- 研究人员：AI模型研究

## TOP 5: Supabase开源Firebase替代（周增1200+star）

### 项目信息

- GitHub: supabase/supabase
- 语言: TypeScript
- 本周star增长: 1200+
- 总star: 70,000+

### 项目简介

Supabase是开源Firebase替代，提供：
- 数据库（PostgreSQL）
- 身份认证
- 存储
- 实时订阅
- Edge Functions

类似Firebase，但完全开源、自托管可控。

### 为什么火爆？

Supabase火爆因为：
- Firebase昂贵（Supabase免费开源）
- 数据可控（自托管）
- 性能强大（PostgreSQL）
- 开发便利（类似Firebase体验）

### 怎么使用？

**快速开始：**
访问supabase.com，创建免费项目。

**使用体验：**
```
import { createClient } from '@supabase/supabase-js'

const supabase = createClient(url, key)
const data = await supabase.from('users').select()
```

**适合谁？**
- 前端开发者：快速构建应用
- 小团队：免费后端服务
- 企业：自托管需求
- 学习者：学习后端开发
